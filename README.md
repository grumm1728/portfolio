# Scott Farrar Portfolio

A lightweight GitHub Pages portfolio with a graph-paper, math-class notebook feel.

## Edit Projects

Featured links live in `script.js` in the `projects` array. Update the title,
description, URL, or thumbnail key to change the cards on the page.

## Publish

This site is designed to publish from the repository root on GitHub Pages.

1. Push the repo to `https://github.com/grumm1728/portfolio`.
2. In GitHub, go to **Settings > Pages**.
3. Set the source to the `main` branch and `/root`.

The page should then be available at:

`https://grumm1728.github.io/portfolio/`
